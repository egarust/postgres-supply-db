# База данных поставок телефонов и запчастей (PostgreSQL)

Курсовая работа по дисциплине «Базы данных» (НГТУ НЭТИ).

## Схема

9 таблиц: `country`, `manufacturer`, `phonetype`, `phonemodel`, `supplier`, `sparepart`, `supplier_sparepart` (многие-ко-многим), `supply`, `stock`.

## Что реализовано

- **18 функций PL/pgSQL** с параметрами: поиск моделей по диапазону цен, выше среднего по стране, производителю или поставщику, статистика ремонтопригодности, поставщики с высоким процентом брака и другие
- Запросы с `INNER`, `LEFT` и `RIGHT JOIN`, агрегатами и подзапросами
- **5 B-tree индексов** под частые фильтры (год выпуска, срок службы, цена, дата поставки, брак) с замером влияния на скорость поиска
- Представление, последовательности, ограничения целостности

## Развернуть

```bash
createdb supply
psql -d supply -f schema.sql
```
